Opportun Media Player

Route audio tracks from one file to multiple outputs — at the same time.

OMP is a free, source-available media player built around one specific problem: playing different audio tracks from the same file through different output devices simultaneously — the original audio on your speakers, a dub or commentary track on someone's headphones, staying in sync.

Download View source

Features

  • Route any audio track to any output device — the same track can fan out to multiple devices at once, each with its own volume.
  • Position subtitles in on-screen zones you define, each fed by its own track.
  • Adjust playback speed without changing pitch.
  • Light, dark, and system themes.
  • Windows, Linux, and macOS.
